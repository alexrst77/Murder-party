Moteur Murder Party

Tout se règle ici ; l’enquête complète se reconstruit à chaque changement, toujours cohérente. Commence par un univers et un type d’affaire, puis modifie n’importe quel champ. Dans les textes, {cible}, {moyen}, {acces}, {trace} reprennent les champs ; {c} désigne le coupable qui agit, {d} la personne qui découvre les faits.

L’affaire

Comment remplir : écris une phrase normale. Là où un nom doit apparaître, mets le mot-clé entre accolades, il sera remplacé automatiquement.
  • {c} = le nom du coupable (tiré au sort, tu n’as rien à faire)
  • {d} = le nom de la personne qui découvre l’affaire
  • {cible}, {moyen}, {acces}, {trace} = ce que tu as tapé dans les cases du même nom juste en dessous
Sous chaque case, l’aperçu montre la phrase telle qu’elle sera imprimée. Si un modèle te convient, tu n’as rien à modifier.

Plan

Le contrôle vérifie la structure : heures, jours, présence simultanée dans deux lieux, balises inconnues, joueurs avec moins de deux faits, conclusions avec moins de deux appuis, fausses pistes sans résolution, logements partagés. Il ne juge pas le plaisir de jeu : fais relire les pièces par quelqu’un qui ignore la solution.

Pour imprimer, ouvre le fichier .html dans Safari ou Chrome, puis Imprimer : chaque fiche sort sur sa propre page.

Le générateur garantit la cohérence ; une IA peut ensuite habiller les textes. Elle doit répondre uniquement par un JSON, que tu colles dans Données JSON.
